# Кликабельный прототип

Открыть `/prototype/` на локальном сервере проекта (`npm run dev`).

Прототип использует вымышленных людей и результаты. Состояние сохраняется только в отдельном ключе `moy-temp-ui-prototype-v1` в localStorage. Рабочая IndexedDB приложения не читается и не изменяется. Сброс: «Ещё» → «Начать проверку заново».

## Маршруты для согласования

1. **Своя тренировка:** «Сегодня» → занятие «Я» → «Начать» → «Готово» → «Завершить» → подтверждение пропущенных → итог.
2. **Клиент:** «Люди» → Анна → «Программы» → программа → день → добавить несколько упражнений, заменить, перетащить → вернуться в карточку → «Начать тренировку».
3. **Пара, свои программы:** «Сегодня» → Максим + Екатерина → «Начать» → ввод результата → переключение участника → завершение одного → продолжение второго.
4. **Пара, общие упражнения:** «Сегодня» → «+» → два участника → «Общие упражнения» → сохранить → начать → отдельное подтверждение результатов участников под общей фотографией.

## Граница прототипа

Проверяем композицию экранов и переходы, а не производственную модель хранения. Фото показаны обозначенными заглушками. Миграция существующих данных, строгая валидация, реальное резервное копирование, устойчивость к повреждённым данным и проверка на физическом iPhone относятся к реализации после согласования.

Не подключать этот прототип вместо рабочего приложения и не переносить демонстрационные данные в пользовательское хранилище.
