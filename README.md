# Мой темп

Мобильный каталог из 80 упражнений, шаблоны тренировок и журнал одного рабочего подхода на упражнение. Данные сохраняются в IndexedDB того браузера, где вы открыли сайт.

## Открыть на телефоне

[Открыть «Мой темп»](https://radiance5100-creator.github.io/liza-trener/) в браузере телефона. Ссылку можно добавить на главный экран через меню браузера. Компьютер для работы с опубликованным сайтом не нужен.

Данные хранятся отдельно в каждом браузере. Если вы уже вносили записи на локальном адресе, экспортируйте резервную копию там и импортируйте файл на телефоне. Регулярно сохраняйте копию через раздел «Данные».

### Запуск как приложение без панели браузера

На iPhone откройте сайт в Safari → «Поделиться» → «На экран Домой». Если доступен переключатель «Открывать как веб-приложение», включите его, затем нажмите «Добавить». Запускайте приложение через иконку «Мой темп» на главном экране. На Android используйте меню Chrome → «Установить приложение» / «Добавить на главный экран» или кнопку установки в приложении, если её поддерживает браузер.

Подсказка доступна под главной плашкой и в настройках. В обычной вкладке сайта панели браузера остаются под управлением браузера. Перед первым запуском с иконки сохраните резервную копию: если браузер выделит приложению отдельное хранилище, её можно импортировать в новом окне. Для загрузки приложения нужен интернет; офлайн-загрузка не добавлена.

## Запуск

```powershell
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://localhost:5173`). Публикация новой версии на GitHub Pages выполняется автоматически после отправки изменений в ветку `main`.

## Использование

- **Упражнения:** поиск, фильтры и сортировка внутри разделов «Ноги», «Спина», «Грудь», «Плечи», «Малые мышечные группы», «Пресс». Нажмите карточку, чтобы открыть редактор на всю высоту экрана, изменить подход, заметку или два скриншота. Изображения открываются в галерее со свайпами.
- **Шаблоны:** создайте тренировку, добавьте упражнения и задайте их порядок перетаскиванием за ручку слева (на телефоне — пальцем). Кнопка «Заменить» выбирает другое упражнение на той же позиции. Доступны также кнопки и клавиши вверх/вниз.
- **Тренировка:** по одному рабочему подходу на упражнение, со слайдером скриншотов. Маленький знак «?» переключает пометку о технике одним нажатием: серый — выключена, акцентный — включена. Без комментариев и дополнительных окон. Пометка сохраняется между тренировками до повторного нажатия. В слайдере остаются только фотографии, без стрелок и счётчика. Черновик сохраняется автоматически; занятие можно отложить и продолжить.
- **Клиенты:** создайте карточку с именем, контактом и заметками, затем добавьте программы из общего каталога. У каждого клиента отдельные результаты, журнал и пометки о технике. В первой тренировке клиента нагрузка и повторы пустые; далее подставляется его последний результат. Личные тренировки обновляют каталог, клиентские — только результаты соответствующего клиента.
- **Данные и настройки:** скачайте резервную копию в JSON или восстановите её из файла. Импорт заменяет все текущие данные после подтверждения.

Скриншоты уменьшаются до 1600 пикселей по длинной стороне для экономии места. Резервная копия включает клиентов, программы, пометки, фото и журнал. Старые копии совместимы: при импорте добавляются пустые коллекции клиентов и пометок. Очищение данных браузера удаляет локальные данные; регулярно сохраняйте резервную копию. Синхронизации между устройствами нет.
